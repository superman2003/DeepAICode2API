# DeepAICode2API Windows 可运行版

包内包含 Windows x64 程序及源码，运行无需安装 Go。
不包含任何本地账号、真实密钥、私有 `.env` 或邮箱令牌。

解压到普通目录，运行 `run-windows.cmd`，保持该窗口运行。
首次运行会生成新 `.env` 和空账号库；管理密码在 `.env`，首次网关 API Key 会显示在控制台。
控制台使用 `http://服务器IP:10087`，服务器防火墙及云安全组需允许相应访问。

## 从旧版安装本版

停止旧程序，备份服务器自己的 `.env` 和 `data`，将本包程序/源码覆盖到同一目录。
本包没有 `.env` 和 `data`，保留原文件即可继续使用原账号和密钥。
然后运行新的 `run-windows.cmd`。首次安装含更新器的完整包需要这一次手动覆盖。

## 后续网页升级

管理网页打开“更新”：检查更新 → 下载并校验 → 安装并重启。
默认来源 `superman2003/DeepAICode2API`，可在页面修改仓库，来源设置保存在 `data/updater`，不改 `.env`。
升级包只替换两个 exe，网页随主程序内嵌更新，账号和 `.env` 均不覆盖。
运行中的注册任务会阻止重启升级；接口在重启期间会短暂断开。
新程序启动失败、版本检查失败或不能读取原账号库时，会恢复旧程序。
需要使用本包的 `run-windows.cmd` 启动；直接启动裸 exe 或旧启动脚本不能执行网页重启。

TempMail.lol、Claude Code、Codex 和注册上限的说明见 `docs/claude-codex.md` 与 `docs/tempmail-lol.md`。
自定义源码后可安装 Go 1.25+，运行启动脚本时加 `-Build` 编译。
